# Madridista Hub — Web Technologies Final Project

Unofficial Real Madrid fan website for MT-2506.

## Features
Six connected pages; responsive Grid/Flexbox layout; persistent light/dark mode; localStorage sign-up/login/profile; player search and position filter; form validation; CSS transitions; accessible labels and focus states.

## Run locally
Open `index.html` in a browser or use VS Code Live Server. All files use relative paths.

## Deploy on GitHub Pages
1. Create a public GitHub repository.
2. Upload the entire contents of this folder to the repository root.
3. Open Settings → Pages → Deploy from branch → main / root → Save.
4. Wait for the published URL, then test all six pages and copy both URLs into the Links.txt file.

## Important security note
Authentication is a frontend-only educational simulation; passwords are stored in browser localStorage as explicitly required for the assignment. Never use a real password. Do not use this approach in production.

## Notes
The player list is illustrative, not a current official squad feed. No external API is required (optional bonus). No club logos or copyrighted photography are included.
